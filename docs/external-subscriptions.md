# Внешние VLESS-подписки

Внешний селектор собирает VLESS-ссылки из публичного HTTPS-источника, проверяет их доступность и отдаёт выбранные ключи в подписках клиентов. Настройка находится в разделе **Ядра → Внешние подписки**.

## Подмодули и источники

Каждый подмодуль задаёт имя, URL источника, интервалы обновления и проверки, число выдаваемых ключей, режим отбора, фильтр стран и режим выбора.

Источник должен быть доступен по публичному HTTPS URL; логин и пароль в URL не поддерживаются. В нём указываются VLESS URI — по одному на строку. Поддерживаются VLESS-ключи с transport/security-параметрами, которые умеют разбирать клиенты проекта; некорректные и неподдерживаемые строки не выдаются. Query-параметры URL сохраняются, а полный адрес источника виден администраторам с `coreSettings`, поэтому не помещайте в него токены, пароли и другие секреты.

Если включена галочка **Название** (по умолчанию включена), имя подмодуля добавляется к имени ключа: `🇷🇺 VK` → `RU · 🇷🇺 VK`. Если галочка снята, остаётся `🇷🇺 VK`.

## Параметры

- **Обновлять список** — интервал повторного получения источника, от 1 до 1440 минут.
- **Повторная проверка ключей** — интервал проверки доступности, от 1 до 1440 минут.
- **Название** — по умолчанию включено; добавляет имя подмодуля перед именем узла в VLESS-ссылке.
- **Количество ключей в подписке** — от 1 до 10.
- **Принудительная смена** — пустое значение отключает периодическую ротацию; допустимый интервал — от 1 до 10080 минут.
- **Фильтр стран** — включать только выбранные флаги или исключать их. Если флаги не выбраны, фильтрация отключена и проходят все узлы. Нужен символ Unicode-флага, например `🇷🇺`; текстовый код страны `ru` не является флагом.
- **Состояние, пинг** — `AUTO` выбирает проверенные ключи автоматически, `A-Z` сохраняет порядок источника, `Z-A` использует обратный порядок.

Число ключей ограничено и числом доступных кандидатов, прошедших фильтр и проверки. Ошибки источника или неудачная проверка не публикуют непроверенный ключ.

## API панели

Маршруты находятся в группе `/panel/core/external-subscriptions` и требуют действующую сессию. Чтение списка разрешено пользователям с `coreSettings`; изменение настроек, создание, переупорядочивание, обновление, ротация и удаление подмодулей, а также остановка и перезапуск селектора доступны только супер-администратору. Проверка прав выполняется на сервере; скрытие кнопок в интерфейсе — только дополнительная подсказка. Клиентам API следует отправлять `X-Requested-With: XMLHttpRequest`, чтобы ошибка авторизации возвращалась JSON-ответом, а не перенаправлением на HTML-страницу входа.

| Метод | Путь | Доступ | Назначение |
|---|---|---|---|
| GET | `/panel/core/external-subscriptions/list` | `coreSettings` | Состояние селектора и данные подмодулей. Секретные URI ключей не возвращаются, но `sourceUrl` возвращается полностью |
| POST | `/panel/core/external-subscriptions/settings` | Супер-администратор | Общие настройки селектора и адреса проверок |
| POST | `/panel/core/external-subscriptions/slots` | Супер-администратор | Создать подмодуль |
| POST | `/panel/core/external-subscriptions/reorder-slots` | Супер-администратор | Изменить порядок подмодулей; поле `data` содержит JSON-массив их ID |
| POST | `/panel/core/external-subscriptions/slots/:id` | Супер-администратор | Изменить подмодуль |
| POST | `/panel/core/external-subscriptions/slots/:id/delete` | Супер-администратор | Удалить подмодуль |
| POST | `/panel/core/external-subscriptions/slots/:id/refresh` | Супер-администратор | Поставить обновление источника в очередь |
| POST | `/panel/core/external-subscriptions/slots/:id/next` | Супер-администратор | Запросить следующий ключ для проверки/смены |
| POST | `/panel/core/restart/external-selector` | Супер-администратор | Перезапустить селектор |
| POST | `/panel/core/stop/external-selector` | Супер-администратор | Остановить селектор |

Операции изменения принимают форму `application/x-www-form-urlencoded`; создание и изменение подмодуля также принимают JSON. Поле `showName` — булево: если оно не передано при создании, значение включено; если не передано при изменении, сохраняется прежнее. В форме `countryFlags` можно передавать повторяющимся параметром. Ответы используют стандартный конверт панели с полями `success`, `msg` и `obj`.
